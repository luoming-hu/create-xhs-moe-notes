# 萌娘知识图解视觉系统

## 基础画风

- 画布使用3:4竖版；目标输出可采用1086×1448像素。
- 使用高品质日系动漫、水彩粉彩、细腻铅笔线稿和温暖纸张颗粒。
- 营造糖果色未来感，颜色丰富但信息层级清晰。
- 使用彩色填充、粗白描边和柔和阴影的大号圆润手写感标题。
- 让中心角色成为视觉主体，使用圆角知识卡片和逻辑连接图。
- 人物是年轻成年女性，可爱但不幼儿化；衣着端正、非性感。
- 避免照片写实、塑料3D、暗黑压抑、幼儿比例、金融符号、无关商标、水印和乱码。

## 角色设计

把抽象概念转化为发型、发饰、服装、道具和配色：

- 机制或工程：结构化制服、工具、节点、齿轮或终端。
- 研究或资料：眼镜、档案、书签、放大镜或文档卡。
- 安全或风险：警示色细节、护盾、锁、停止手势。
- 检索或连接：路线、光链、索引卡、数据库或传送节点。

群像总分式为每个独立部分设计不同角色；单主角递进式固定同一张脸、眼睛、发型、服装和核心道具，只改变表情、动作、镜头和场景。

## 英文身份框

- 每位角色第一次出现时，在头顶附近添加一个与人物轮廓分离的悬浮展示框。
- 身份框只使用英文；优先使用标准短称或常用缩写，如`LLM`、`Transformer`、`RAG`、`Chain of Thought`、`AI Agent`。
- 完整英文太长时改用常用缩写，不缩小字号强塞。
- 同页首次出现多位角色时，每位角色各有独立身份框。
- 同一角色后续页面不再重复身份框。
- 后续首次出现新角色时自动添加身份框，不暂停生成。

## 表情与动作

- 定义：好奇、恍然或轻微惊讶。
- 机制：专注、严肃、排列节点。
- 案例：兴奋发现、演示或操作。
- 教程：冷静讲解、指向步骤。
- 风险：警觉、不笑、停止或提醒。
- 总结：笃定、完成感或团队协作。

允许少数页面重复表情，但整套必须出现明显变化，不能全部使用相同笑容。所有动作必须服从[视觉硬规则与样图](visual-qa.md)中的手部检查。

## 固定角标

- 左上：`AI`。
- 右上：页码分数，如`1/6`、`6/6`。
- 左下：`luoming`。
- 右下：逐页自动提炼的关键词，最多4个字符。

封面右下使用总概念；分图使用当前知识点。确实无合适关键词时取消整个角标，不保留空框、花括号或占位。角标尺寸约为早期样例的60%，保持低视觉权重。

## 文字载体

允许文字出现在标题、副标题、角标、英文身份框、知识卡、逻辑节点、对话框，以及书本、报告、文件、屏幕、终端和展示板等合理信息载体上。

禁止把文字直接放在头发、呆毛、皇冠、发饰、脸部、皮肤、衣服、首饰、腰带、鞋袜、丝带、披风和身体光效上。即使文字正确，也必须判定为不合格。完整规则见[视觉硬规则与样图](visual-qa.md)。

## 使用参考图

- 风格参考位于`assets/style-references/`。
- 正面布局参考位于`assets/layout-references/positive/`。
- 反面质检案例位于`assets/qa-examples/negative/`，绝不能传给生图工具。
- 样图库数量不限；每次只选择最相关的正面样图，单次最多5张。
- 生成封面时优先选择相关风格图和逻辑布局正例。
- 生成后续页面时优先使用已确认封面或首次合格角色页，再搭配必要风格图。
- 参考图只锚定被明确指定的画风、布局或身份表现；忽略其中旧主题、旧页码和旧角标。

## 单页提示结构

每次只生成一个页面，并依次说明：

1. 画布比例和整体风格。
2. 角色不可变化的身份特征。
3. 首次出现时的英文身份框，或明确禁止重复身份框。
4. 当前页表情、动作、自然手部与核心道具。
5. 页面标题、结论、知识点和精确可见文字。
6. 允许文字的载体与人物文字禁区。
7. 卡片位置、逻辑连接、背景和留白。
8. 四角角标及当前页码、关键词。
9. 禁止项：多指、少指、粘连手指、人物身上文字、旧角标、额外文字、乱码、水印、错误页码和无关元素。
