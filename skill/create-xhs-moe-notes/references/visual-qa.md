# 视觉硬规则与样图

在编写生图提示、检查生成结果或修复图片前读取本文件。

## 手部硬规则

- 张开的手必须清楚表现五根结构自然的手指。
- 握书、握笔或拿道具时允许部分手指被自然遮挡，但数量关系、关节、朝向和抓握姿势必须合理。
- 把多指、少指、粘连、断裂、扭曲、结构融合或不自然抓握判定为硬失败。
- 不得为了掩盖错误而临时裁掉手部或增加无关遮挡物。
- 自然构图原本就只展示部分手部时允许合理遮挡。
- 使用原始清晰度放大检查每一只可见手；不要只看缩略图。

## 人物文字禁区

禁止文字出现在：

- 头发、呆毛、发梢。
- 皇冠、发饰、头饰。
- 脸部、皮肤、身体。
- 衣服、首饰、腰带、鞋袜。
- 丝带、披风、身体光效。
- 直接覆盖人物轮廓的漂浮文字。

允许文字出现在：

- 与人物轮廓分离的英文身份框。
- 主标题、副标题和固定角标。
- 知识卡、逻辑节点、对话框。
- 书本、报告、文件、屏幕、终端和展示板等合理的信息载体。

人物禁区出现任何文字时，即使拼写正确，也判定为硬失败。

## 身份框硬规则

- 每位角色第一次出现时必须拥有独立悬浮身份框。
- 身份框放在头顶附近但不与头发或头饰融合。
- 只显示确认稿登记的英文短称或缩写。
- 同一角色后续页面不得重复身份框。
- 首次同页出现多位角色时必须分别标注，不能用一个总框代替。

## 封面逻辑硬规则

- 封面必须使用主框架对应的路线、箭头、环路、树、分支或模块网络。
- 给核心节点使用独立内容编号`1...K`，编号顺序服从后续阅读顺序。
- 内容编号与右上分数页码独立，不要求数值对应。
- 卡片齐全但没有连接关系时，判定为结构失败。
- 连线必须表达真实关系，不能只是装饰线。

## 检查结论

逐项标记`合格`或`失败`：

1. 手部结构。
2. 人物文字禁区。
3. 首次出现身份框。
4. 封面逻辑关系。
5. 标题、正文、角标和页码。
6. 角色连续性与表情变化。

任一硬规则失败时不得进入下一生成阶段。只修复问题页，并遵守每页最多2次自动修复的限制。
